# zero2python

Учебный терминал команды для Python, нейросетей и анализа данных. Next.js App Router, React, TypeScript; Python выполняется в браузере через Pyodide.

Карта открывает уроки последовательно. В уроке материал и редактор находятся в отдельных панелях. Есть вопрос дня, разделы книги и университета, личная статистика и общий лидерборд с входом по приглашению команды. Материалы книги и университета ожидаются; проверочный пример книги явно отделен от учебного прогресса.

## Запуск

Нужен **Node.js >=22.13.0** с `node:sqlite`.

```bash
npm ci
npm run dev
```

Откройте [localhost:3000/app](http://localhost:3000/app). Без настройки команды доступно локальное обучение. Для общего прогресса скопируйте `.env.example` в `.env.local`, задайте случайный `TEAM_INVITE_CODE` (не менее 16 символов) и перезапустите сервер. Данные хранятся в `data/private/team.sqlite`; для другого размещения задайте `TEAM_DB_PATH`. Все участники подключаются к одному серверу.

```bash
npm run check
node node_modules/typescript/bin/tsc --noEmit --incremental false
npm run build
npm start
```

Браузерная проверка, синтетические данные и эксплуатационные настройки описаны в [system.md](docs/system.md). Скриншоты проверок и локальные данные не коммитятся.

## Что учесть

- Существующий шрифт загружается при сборке; первый запуск Pyodide и numpy/pandas требует сети.
- Старый `py-term.v1` сохраняется. У вошедших участников отдельный профиль с серверной синхронизацией; перенос гостевого прогресса выполняется явной кнопкой.
- Рейтинг доступен участникам команды и сортируется по решенным задачам Python. Равный результат дает равное место; чтение и тесты не входят в общий балл.
- Серверу нужен постоянный диск. Подключение внешней БД для нескольких хостов, восстановление пароля и деплой остаются последующими этапами.
- Проверки Python выполняются в браузере и доступны клиенту. Это учебная практика, а не защищенный экзамен; прежнее отсутствие ограничения времени выполнения остается открытым вопросом.
