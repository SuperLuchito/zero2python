# zero2python

Учебная платформа команды для изучения Python с нуля, основ нейросетей и анализа данных. Раздел университетского курса должен открываться после освоения необходимых тем Python.

Текущий каркас — «Терминал для Python»: приложение на Next.js (App Router), React и TypeScript. Уже есть уроки, практика с Pyodide в браузере и вопрос дня. Прогресс хранится в `localStorage` текущего браузера; аккаунтов и синхронизации между устройствами пока нет.

## Запуск

В каталоге проекта установите зависимости по lock-файлу и запустите приложение:

```bash
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000) и нажмите Enter на загрузочном экране.

Сборка и запуск собранного приложения:

```bash
npm run build
npm start
```

Проверка типов без записи файлов:

```bash
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

Это существующие команды проекта. При настройке правил выполнена проверка типов; сборка и браузерный сценарий в рамках этой задачи не запускались.

## Ограничения каркаса

- Первый запуск Python загружает Pyodide с CDN; нужен интернет.
- numpy/pandas подгружаются лениво для уроков с данными; загрузка может занять время.
- Это не Jupyter. Код и проверки заданий выполняются в одном браузерном интерпретаторе; проверки доступны клиенту.
- Уроки пока доступны напрямую; открытие раздела анализа данных по предпосылкам предстоит реализовать.
- Существующий контент — основа для переработки в последовательный курс с нуля. Материалы книги и университета еще ожидаются.
