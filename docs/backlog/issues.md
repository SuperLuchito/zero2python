# Учет задач

После начала работы с GitHub источником статусов и приемки служат Issues. Этот файл хранит правила подготовки и только еще не опубликованные заготовки, а не копию удаленного бэклога.

## Подготовка

1. Выбрать шаблон: задача, ошибка или исследование из `.github/ISSUE_TEMPLATE/`.
2. Описать ожидаемый результат, границы, критерии приемки, проверки и зависимости.
3. Проверить существующие Issues и PR на дубликаты.
4. При поручении создать задачи опубликовать Issue, поставить подходящие метки из `.github/labels.yml`, указать этап и связанные материалы.
5. Заменить локальную заготовку ссылкой на Issue. Актуальные статусы дальше читать из GitHub.

Принятые решения о рейтинге и общих данных находятся в [ADR 0001](../decisions/0001-shared-progress.md); оставшиеся вопросы — в [questions.md](../questions.md).
