# Этапы проекта

Это локальный план из поручения пользователя. Удаленные GitHub Milestones еще не созданы; даты и количественные цели не утверждены.

| Этап | Цель | Критерий завершения |
| --- | --- | --- |
| M1. Репозиторий и основа | Подготовить правила работы и подключить существующий каркас | Навыки и документы проверены; каркас исследован и запускается; первичная публикация выполнена после поручения пользователя |
| M2. Дизайн | Внести согласованные визуальные изменения | Измененные страницы и взаимодействия проверены на согласованных размерах экрана |
| M3. Учебные направления | Встроить Python, нейросети и университетский анализ данных | Материалы и задания проверены; правила открытия анализа данных определены и работают |
| M4. Регистрация | Добавить простой вход и согласованное хранение прогресса | Участник может войти и продолжить обучение с сохраненного состояния |
| M5. Запуск | Развернуть и начать пользоваться командой | Рабочий адрес доступен; проверен полный учебный сценарий; описаны запуск и обслуживание |

Детальные Issues формируются перед соответствующим этапом, когда известны входные материалы и проверяемые критерии. Учет задач описан в [issues.md](issues.md).
