## L01. Последовательность и присваивание

### L01-T01. Снимок очереди

**Ступень 1.** Перед обработкой камера имеет `queued` кадров, обработчик уже завершил `processed` кадров. Сохраните в `before` размер очереди до текущего шага, затем перенесите `batch` кадров из очереди в обработанные. `queued`, `processed`, `before` — целые числа. Вход: `0 <= batch <= queued`, `processed >= 0`. Нужны три итоговых значения; нельзя подставить в решение готовые числа вместо вычислений.

```python

processed = 3

# Ваш код
```

| Вход: queued, processed, batch | Результат: before, queued, processed |
| --- | --- |
| 12, 3, 5 | 12, 7, 8 |
| 0, 3, 0 | 0, 0, 3 |
| 5, 0, 5 | 5, 0, 5 |

**Проверяем:** снимок сделан до изменения; число кадров не потеряно.

<details><summary>Подсказка 1</summary>

</details>

<details><summary>Подсказка 2</summary>

Сначала `before = queued`. Затем уменьшите очередь на `batch` и увеличьте `processed` на то же число.

<details><summary>Разбор после решения</summary>

Порядок присваиваний здесь часть контракта. Проверьте сохранение общего количества: начальные `queued + processed` должны совпадать с итоговыми. `before` после изменения очереди само не обновляется.
</details>

### L01-T02. Калибровка в неправильном порядке

**Ступень 2.** Датчик выдает целое `raw`. По правилу калибровки сначала нужно вычесть целое смещение `offset`, затем умножить на целый коэффициент `gain`. Исправьте последнюю строку. Результат `corrected` — целое число. Входные значения могут быть отрицательными или нулевыми.

```python
raw = 17
offset = 5
gain = 3
corrected = raw * gain - offset
```

Примеры: `(17, 5, 3) → 36`; `(5, 5, 9) → 0`; `(-2, 3, 2) → -10`.

**Проверяем:** решение отражает порядок операций, а не просто проходит на нулевом смещении.

<details><summary>Подсказка 1</summary>

Какое промежуточное значение должно быть готово до умножения?
</details>

<details><summary>Подсказка 2</summary>

Скобки позволяют вычислить разность целиком до применения коэффициента.
</details>

<details><summary>Разбор после решения</summary>

`raw * gain - offset` изменяет масштаб исходного показания; `(raw - offset) * gain` — показания без смещения. Придумайте вход, где ошибочная формула случайно дает правильный результат. Например, `offset = 0`: такой единственный тест не обнаружит ошибку.
</details>

## L02. Числа и единицы

## L04. Условия и границы

### L04-T01. Нулевая задержка — тоже настройка

**Ступень 1.** `delay` — неотрицательное целое число миллисекунд или `None`. `fallback` — неотрицательное целое. Вычислите целое `actual`: используйте `fallback` только при отсутствии `delay`. Ноль означает запуск без задержки и должен сохраниться.

```python
delay = 0
fallback = 10
# Ваш код
```

Примеры: `(0, 10) → 0`; `(None, 10) → 10`; `(7, 10) → 7`; `(None, 0) → 0`.

**Проверяем:** отсутствие не спутано с ложным значением.

<details><summary>Подсказка 1</summary>

Обычная проверка истинности объединяет несколько разных значений. Условие задачи выделяет ровно одно.
</details>

<details><summary>Подсказка 2</summary>

Запишите ветку `if delay is None`, а в оставшейся ветке сохраните исходное значение.
</details>

<details><summary>Разбор после решения</summary>

`delay or fallback` выглядит удобно, но подменяет нулевую задержку. Проверки `None`, нуля и положительного значения вместе обнаруживают это смешение.
</details>

### L04-T02. Одновременно перегрелся и отключился

**Ступень 2.** Выберите одну строку `status`. Вход: `online` — `bool`, `battery` — целое от 0 до 100, `temperature` — целое от -100 до 150. Правила в порядке убывания приоритета: если устройство не в сети — `offline`; иначе при батарее не больше 10 — `low-battery`; иначе при температуре не меньше 80 — `hot`; иначе — `ready`. При совпадении условий действует первое.

```python
online = False
battery = 5
temperature = 90
# Ваш код
```

Примеры: `(False, 5, 90) → "offline"`; `(True, 10, 80) → "low-battery"`; `(True, 11, 80) → "hot"`; `(True, 11, 79) → "ready"`.

**Проверяем:** приоритет и включенные границы.

<details><summary>Подсказка 1</summary>

Независимые `if` могут перезаписывать уже выбранный статус.
</details>

<details><summary>Подсказка 2</summary>
