## L01. Программа помнит результат, а не обещание

**До урока:** ничего. **После урока:** сможете прочитать короткую программу по шагам и объяснить значение каждого имени. **Новые конструкции:** числа, строки в кавычках, `=`, `+`, `-`, `*`, `print()`, комментарий `#`.

### Программа — последовательность действий

Камера сделала несколько снимков. Нужно узнать, сколько осталось обработать:

```python
captured = 11
processed = 4
remaining = captured - processed
print(remaining)
```

На экране появится `7`. Читаем сверху вниз: связали имя `captured` со значением `11`, имя `processed` — с `4`, вычислили разность, сохранили результат под именем `remaining`, показали его.

Интерпретатор — программа, которая исполняет код Python. Выражение — запись, которую можно вычислить: например, `captured - processed`. `print(...)` — вызов готовой функции: она выводит переданные значения. Скобки отделяют то, что мы передаем функции. Функция может делать работу за нас; писать собственные начнем позже.

### Знак `=` задает действие

В Python присваивание не утверждает математическое равенство. Оно сначала вычисляет правую часть, затем связывает результат с именем слева:

```python
processed = 4
processed = processed + 2
print(processed)
```

Результат — `6`. В правой части второй строки используется прежнее значение `processed`. После присваивания это имя обозначает новое значение. Никакого уравнения с неизвестным Python не решает.

Имена нужны, чтобы выражать смысл: `frame_count` понятнее, чем `x`, когда речь о числе кадров. В имени можно использовать буквы, цифры и `_`, но нельзя начинать с цифры. Регистр имеет значение: `count` и `Count` — разные имена. В наших примерах используем латиницу и слова через `_`.

### Вычисленное значение не обновляется само

```python
temperature = 20
saved = temperature
temperature = 25
print(saved, temperature)
```

Вывод: `20 25`. `saved` хранит результат того присваивания. Оно не становится формулой «всегда брать текущее значение temperature». Аналогично ранее вычисленное `remaining` не изменится после изменения `processed`: разность придется вычислить заново.

Сейчас мы работаем с числами и текстом. У изменяемых коллекций позже появится важный нюанс: разные имена могут обозначать один изменяемый объект. Пока достаточно помнить, что присваивание само по себе не создает живую связь между именами.

### Что вводить и что читать

```python
status = "ready"
print("Статус:", status)
# Здесь объясняем замысел; Python не исполняет комментарий.
```

`"ready"` — строка, то есть текстовое значение. Кавычки отмечают границы текста и не входят в вывод. Имя `status` написано без кавычек, поэтому Python берет связанное с ним значение. `print` разделяет несколько аргументов пробелом и завершает вывод переводом строки.

В редакторе одиночное выражение может ничего не показать. Чтобы увидеть результат скрипта, используйте `print`. Значки `>>>`, которые иногда видны в документации, — приглашение интерактивного интерпретатора; в код их переносить не нужно.

### Ошибка дает место для проверки

Если написать `print(total)` до определения `total`, возникнет `NameError`: Python не нашел имя. Опечатка в кавычках может привести к `SyntaxError`: код не удалось разобрать. Сначала прочитайте последнюю строку сообщения об ошибке, затем найдите указанный участок. Не меняйте случайные строки в надежде, что ошибка исчезнет.

### Проверьте понимание

Выпишите вывод до запуска:

```python
left = 3
right = left
left = right + 5
print(left, right)
```

Ответ: `8 3`. Во второй строке вычислено значение `3`; третья строка меняет только связь имени `left`. Если результат не совпал с прогнозом, распишите значения после каждой строки.

## L02. Число должно означать что-то конкретное

**До урока:** L01. **После урока:** сможете выбрать числовую операцию под задачу, преобразовать строку и разобраться с остатком. **Новые конструкции:** `int`, `float`, `str`, `/`, `//`, `%`, `**`, скобки, преобразования `int()`, `float()`, `str()`, `type()`.

### Тип определяет смысл операции

```python
print(8 + 2)
print("8" + "2")
```

Вывод: сначала `10`, затем `82`. В первом случае складываются целые числа, во втором соединяются строки. `"8" + 2` вызовет `TypeError`: Python не выбирает за нас, нужно ли сложить числа или склеить текст.

`int` представляет целые числа: `0`, `12`, `-7`. Для чтения больших чисел в коде можно разделять цифры символом `_`: `1_000_000` — то же число, что `1000000`. `float` — числа с плавающей точкой, например `0.5` и `-2.75`. Чтобы посмотреть тип значения, используйте `print(type(value))`. У значения есть тип, даже если вы не написали его рядом с именем.

Текст из файла или формы сам собой не становится числом:

```python
raw = " 18 "
count = int(raw)
print(count + 2)
```

Получится `20`. `int("18")` читает запись целого числа; `int("18.5")` вызовет `ValueError`. `float("18.5")` читает дробную запись. Десятичный разделитель здесь — точка. `str(18)` делает строку `"18"`.

`int(18.9)` дает `18`: преобразование уже числового значения отбрасывает дробную часть в сторону нуля. Поэтому `int(-18.9)` дает `-18`. Это не округление до ближайшего целого.

### Три операции деления

Пусть есть 29 кадров, которые складывают в пакеты по 6:

```python
frames = 29
capacity = 6
print(frames / capacity)
print(frames // capacity)
print(frames % capacity)
```

`/` вычисляет обычное частное, для чисел `int` результат имеет тип `float`. `//` дает частное с округлением вниз; здесь `4`. `%` дает остаток; здесь `5`. Значит, есть четыре полных пакета и еще пять кадров.

Полезная связь для целых чисел при ненулевом делителе:

```text
число = делитель * частное_с_округлением_вниз + остаток
```

Все три операции требуют ненулевого делителя. При делении на ноль возникает `ZeroDivisionError`; корректные условия первых задач исключают такой ввод.

### Отрицательные значения показывают разницу

`-1 // 8` равно `-1`, а `-1 % 8` равно `7`: равенство `-1 = 8 * (-1) + 7` сохраняется. При положительном целом делителе остаток попадает от нуля до делителя, не включая верхнюю границу. Это удобно для движения по кольцу: сдвиг из позиции ноль на один шаг назад приводит в последнюю позицию.

Не подменяйте `//` записью `int(a / b)`. У отрицательных чисел результат может различаться, а промежуточный `float` добавляет ненужную потерю точности для больших целых.

### Единицы и порядок действий

Умножение и деление выполняются раньше сложения и вычитания. Скобки делают замысел явным: `(raw - offset) * gain` означает сначала убрать смещение, потом изменить масштаб. `2 ** 3` — возведение в степень, результат `8`.

Имя `duration_ms` сообщает больше, чем `duration`: оно фиксирует миллисекунды. Python не заметит, если сложить миллисекунды с секундами; об этом должны позаботиться условие, имена и проверки.

`float` приближенно представляет многие десятичные дроби. Например, `print(0.1 + 0.2)` обычно показывает `0.30000000000000004`. Это свойство двоичного представления, а не случайная поломка. Пока не изучили сравнение с допуском, задачи на точное количество считаем целыми числами. Подробный разбор точности будет нужен перед измерениями и NumPy.

### Проверьте понимание

Что покажут `print(-9 // 4, -9 % 4)` и `print(int(-2.9))`? Ответ: `-3 3` и `-2`. В первом случае округляем частное вниз, во втором отбрасываем дробную часть в сторону нуля. Это два разных правила.

## L03. Текст: меняем представление, сохраняем смысл

**До урока:** L01–L02. **После урока:** сможете очистить метку, извлечь часть строки и собрать результат. **Новые конструкции:** `len()`, индекс, срез, `.strip()`, `.lower()`, `.replace()`, `.count()`, f-строка, повтор строки.

### Строка — последовательность

```python
label = "CAM42"
print(len(label))
print(label[0], label[-1])
```

Вывод: `5`, затем `C 2`. Индексация начинается с нуля: первый символ имеет индекс `0`, второй — `1`. Отрицательный индекс отсчитывается с конца; `-1` — последний символ. У пустой строки нет даже первого символа, а индекс за границами вызывает `IndexError`.

Срез извлекает фрагмент: `label[1:4]` дает `"AM4"`. Левая граница включена, правая исключена. Длина такого фрагмента при границах внутри строки — `4 - 1`. Записи `label[:3]` и `label[3:]` означают «до позиции 3» и «начиная с позиции 3».

У среза есть полезная мягкость: `label[:100]` вернет всю строку. `label[2:2]` даст пустую строку, потому что между одинаковыми границами нет элементов. Это не то же самое, что чтение одного символа по индексу.

### Строковые операции возвращают результат

```python
raw = "  CAM_A  "
clean = raw.strip().lower().replace("_", "-")
print(raw)
print(clean)
```

В `raw` остался исходный текст, а в `clean` получилось `"cam-a"`. Строки неизменяемы. Операция создает результат, и его нужно сохранить или сразу использовать. Вызов `raw.strip()` без присваивания не переписывает `raw`.

Запись через точку вызывает метод — функцию, связанную со значением. `.strip()` без аргументов убирает пробельные символы по краям; `.lower()` переводит регистр; `.replace(old, new)` заменяет все вхождения указанного фрагмента. Цепочка читается слева направо: результат одного шага получает следующий метод. Когда цепочка плохо читается, сохраните промежуточный результат в понятное имя.

У `.strip("ab")` другой контракт: удалить с краев любые символы из набора `a` и `b`. Это не команда «удалить точный префикс ab». Например, `"baabXabba".strip("ab")` даст `"X"`. Для известного по условию суффикса фиксированной длины можно использовать срез; произвольные имена файлов требуют более точного правила, которое разберем позже.

### Как собрать текст

```python
sensor = "cam-a"
frames = 7
message = f"{sensor}: {frames} кадров"
print(message)
```

Буква `f` перед кавычками разрешает вставить значения выражений внутри `{...}`. Число автоматически получает текстовое представление. Это удобнее, чем каждый раз писать `str(frames)` и склеивать части через `+`.

Оператор `*` повторяет строку: `"*" * 4` дает `"****"`, а повтор ноль раз — `""`. Метод `.count("x")` считает вхождения указанного фрагмента; для многосимвольного фрагмента вхождения не перекрываются. Например, `"aaaa".count("aa")` дает `2`.

### Что не видно глазами

Пробел, перевод строки `\n` и табуляция `\t` — тоже символы. В записи строки обратная косая черта вводит escape-последовательность: `"A\nB"` содержит три символа и печатается на двух строках. `""` — строка длины ноль, а `" "` — длины один.

`len()` строки считает кодовые точки Unicode, а не байты файла и не всегда визуальные значки. Составной символ или emoji может занимать несколько позиций. Первые задачи используют простой алфавит и ASCII-цифры, чтобы проверять текущую тему; работу с произвольным пользовательским Unicode разберем отдельно. `.lower()` полезен для наших меток, но сам по себе не решает все задачи сравнения человеческого текста.

### Проверьте понимание

Чему равно `"frame.csv"[:-4]`? Ответ: `"frame"`. Отрицательная правая граница находится за четыре символа до конца. А `"frame.csv".strip(".csv")` не является общим способом удаления расширения: он работает с набором символов по обоим краям.

## L04. Условия: особенно внимательно на границе

**До урока:** L01–L03. **После урока:** сможете выразить правило словами и кодом, отличить отсутствие значения от нуля. **Новые конструкции:** `bool`, `True`/`False`, сравнения, `if`/`elif`/`else`, `and`/`or`/`not`, `None`, `is None`.

### Сравнение дает ответ

`temperature >= 70` — выражение со значением `True` или `False`. Эти два значения имеют тип `bool`. Сравнивать можно на равенство `==`, неравенство `!=`, меньше `<`, больше `>`, меньше или равно `<=`, больше или равно `>=`.

Не путайте `=` и `==`: первое присваивает, второе сравнивает. Python также разрешает цепочку `0 <= level <= 100`; она проверяет обе границы.

```python
temperature = 70
if temperature >= 70:
    status = "hot"
else:
    status = "ok"
print(status)
```

Вывод — `hot`. Двоеточие открывает блок. Отступ показывает, какие строки принадлежат ветке; в примерах используем четыре пробела. Без отступа нельзя понять структуру программы, поэтому он часть синтаксиса. `print` стоит вне веток и выполняется после выбора.

### Порядок проверок задает приоритет

```python
online = False
temperature = 85
if not online:
    status = "offline"
elif temperature >= 70:
    status = "hot"
else:
    status = "ok"
```

Получится `offline`: в цепочке выполняется первая подходящая ветка. `elif` означает «иначе, если». Несколько отдельных `if` — другое правило: каждый из них проверяется независимо и может перезаписать результат предыдущего. Сначала сформулируйте, что важнее при одновременном выполнении условий.

`and` требует оба условия, `or` — хотя бы одно, `not` меняет истинность. Например, `online and temperature < 70`. Для сложных сочетаний используйте скобки, чтобы правило читалось без мысленного экзамена на приоритеты.

### Отсутствие и ноль — разные данные

`None` — специальное значение для отсутствующего результата или данных. Задержка `0` может означать «запустить немедленно», а `None` — «задержка не задана». Условие `if delay` считает ложными и ноль, и `None`, поэтому здесь оно слишком широкое:

```python
delay = 0
if delay is None:
    actual = 10
else:
    actual = delay
print(actual)
```

Вывод — `0`. Для отсутствия значения используем `is None`. Общее различие идентичности `is` и равенства `==` подробно разберем с объектами; сейчас не используйте `is` для сравнения чисел или строк.

Пустая строка тоже ложна, но строка `"0"` непустая и потому истинна. Истинность не означает, что значение корректно для вашей предметной задачи: непустая строка `"wrong"` от этого не становится числом.

### Правая часть может не выполняться

```python
total = 0
done = 0
enough = total > 0 and done / total >= 0.8
print(enough)
```

Результат — `False`, ошибки деления нет. `and` прекращает вычисление, когда слева уже ложь. `or` прекращает его, когда слева уже истина. Это короткое замыкание; порядок частей имеет значение.

Дополнительный нюанс: `and` и `or` возвращают один из своих операндов, не обязательно `bool`. Например, `0 or 10` дает `10`, а `"ok" and 7` — `7`. Когда нужен строго логический ответ, собирайте его из сравнений или явно преобразуйте через `bool(...)`.

### Проверьте понимание

Интервал `[start, end)` включает начало и исключает конец. Встречи `[10, 20)` и `[20, 30)` не пересекаются: в момент 20 первая уже закончилась. Поэтому проверка соприкосновения не должна автоматически считать его общим занятым временем. Пустой интервал `[20, 20)` вообще не занимает времени.

## L05. Функция: результат по договоренности

**До урока:** L01–L04. **После урока:** сможете написать небольшую функцию с понятным входом и результатом и проверить ее вызовами. **Новые конструкции:** `def`, параметры, вызов, `return`, аргумент по умолчанию, локальные имена, `assert`.

### От одного примера к повторяемой операции

До сих пор данные жили в начале скрипта. Чтобы применить правило к другой метке, приходилось менять код. Функция дает операции имя и принимает данные при вызове:

```python
def make_label(name):
    clean = name.strip().lower()
    return f"sensor:{clean}"

first = make_label(" NORTH ")
second = make_label("south")
print(first, second)
```

Вывод: `sensor:north sensor:south`. `def` определяет функцию. `name` — параметр, имя для входа внутри нее. `" NORTH "` — аргумент, конкретное значение, переданное при вызове. После двоеточия идет тело с отступом.

Определение функции не выполняет ее тело. Работа начинается при вызове `make_label(...)`. При каждом вызове параметр получает переданный аргумент, вычисляется `clean`, затем `return` возвращает результат в место вызова.

### Вернуть и напечатать — разные действия

```python
def show_double(value):
    print(value * 2)

result = show_double(5)
print(result)
```

На экране будут `10` и `None`. Функция показала число, но не вернула его через `return`. Если выполнение дошло до конца тела без `return` со значением, результатом вызова становится `None`.

Чтобы использовать число дальше, напишите `return value * 2`. Печать оставьте тому коду, который отвечает за показ. Так одну функцию можно вызвать из интерфейса, проверки или другой функции.

### Контракт важнее догадок

Перед реализацией ответьте на четыре вопроса: какие значения получает функция, что возвращает, какие входы допустимы, что происходит на границе.

Например: «`level` — целое число от 0 до 100; результат — строка; ниже 20 вернуть `low`, иначе `ok`». Это уже достаточно точное правило. Если условия гарантируют допустимый вход, не нужно добавлять произвольное поведение для списка, словаря или текста. Обработку ошибочного ввода изучим отдельно.

```python
def battery_status(level, threshold=20):
    if level < threshold:
        return "low"
    return "ok"
```

`threshold=20` задает аргумент по умолчанию. `battery_status(15)` использует порог 20; `battery_status(15, threshold=10)` — порог 10. Запись с именем аргумента помогает читать вызов. В первых примерах defaults — числа; изменяемые defaults требуют отдельного объяснения позже.

### Возврат завершает текущий вызов

Когда выполняется `return`, оставшиеся строки тела этого вызова не исполняются. Поэтому после возвращающей ветки иногда не нужен `else`: до следующего `return` доберутся только оставшиеся случаи.

Параметры и созданные внутри функции имена обычно локальны: они нужны этому вызову. Имя `clean` из первого примера нельзя просто прочитать снаружи. Лучше вернуть нужное значение, чем создавать скрытую зависимость от внешней переменной. Области видимости подробнее разберем позже.

### Проверка делает ожидание явным

```python
assert battery_status(19) == "low"
assert battery_status(20) == "ok"
assert battery_status(15, threshold=10) == "ok"
```

`assert` проверяет утверждение. Когда оно истинно, выполнение продолжается; когда ложно — возникает `AssertionError`. В учебном запуске это короткий способ сверить результат с ожиданием. Для обязательной проверки пользовательского ввода в настоящем приложении `assert` не подходит: Python может отключать такие проверки при оптимизированном запуске.

Подбирайте не только удобный пример, но и границу, пустое значение, повторный вызов. Полноценное проектирование тестов будет отдельной темой; читать короткие проверки уже полезно.

### Проверьте понимание

Если `battery_status(20)` вернула `"ok"`, что вернет повторный вызов с теми же аргументами? Здесь снова `"ok"`: функция зависит только от входа и не меняет внешнее состояние. Такое поведение упрощает поиск ошибок и перенос кода.

## L06. Цикл: что нужно помнить между шагами

**До урока:** L01–L05. **После урока:** сможете пройти по строке, накопить результат и обработать границу последовательности. **Новые конструкции:** `for`, `in`, `range()`, накопитель, ранний выход из функции внутри цикла.

### Один шаг для каждого элемента

```python
for symbol in "LRL":
    print(symbol)
```

Вывод — три строки: `L`, `R`, `L`. Цикл по очереди связывает имя `symbol` с очередным символом и выполняет тело с отступом. Для пустой строки тело не выполнится ни разу. Поэтому результат, который понадобится после цикла, нужно подготовить заранее.

У `in` есть и другое применение — проверка принадлежности. Выражение `"R" in "LR"` дает `True`, а `"X" in "LR"` — `False`. В условии можно написать `if symbol not in "LR":`. Для строк это поиск подстроки; в наших задачах `symbol` содержит один символ.

### Результат накапливается по шагам

```python
def count_marks(text):
    count = 0
    for symbol in text:
        if symbol == "!":
            count = count + 1
    return count

assert count_marks("go!! stop!") == 3
assert count_marks("") == 0
```

Имя `count` — накопитель. Перед первым шагом он равен нулю. После каждого шага он хранит число восклицательных знаков в уже просмотренной части строки. Последнее предложение — инвариант: описание того, что остается верным после каждого шага. Оно помогает проверить алгоритм, а не только запомнить код.

Если поставить `count = 0` внутрь цикла, история будет стираться на каждом шаге. Если поставить финальный `return` внутри цикла без условия, функция закончит работу после первого символа. Отступ здесь определяет не внешний вид, а поведение.

### Когда нужен номер шага

```python
for index in range(3):
    print(index)
```

Получим `0`, `1`, `2`. `range(stop)` дает целые числа от нуля до `stop`, не включая его. `range(start, stop)` начинает с `start`; `range(start, stop, step)` задает шаг. Например, `range(3, 0, -1)` дает `3`, `2`, `1`. Шаг не может равняться нулю.

Для доступа по индексу используем `range(len(text))`. Если номер не нужен, прямой обход `for symbol in text` обычно понятнее. Не называйте `range` готовым списком: это отдельное представление целочисленной последовательности, которое не хранит все ее элементы как список.

### У задачи может быть несколько видов памяти

Предположим, ищем самую длинную непрерывную серию сигнала. Нужны два значения: длина серии, которая продолжается сейчас, и лучший результат среди просмотренных частей. При разрыве текущую длину сбрасываем, лучший результат сохраняем. Один счетчик всех подходящих символов не различит `"11011"` и `"11110"`, хотя длины серий у них различны.

Перед циклом запишите смысл каждого такого имени одним предложением. Если вы не можете объяснить, что оно хранит после очередного шага, код пока будет трудно проверять.

### Первый ответ и последний фрагмент

Когда нужен первый подходящий момент, ранний `return` внутри цикла полезен: мы нашли ответ и заканчиваем. Для случая «не найдено» нужен отдельный возврат после цикла, например `None`. Договоритесь, чем отличается индекс с нуля от номера шага с единицы.

Когда обрабатываем серии одинаковых символов, обнаружение нового символа завершает предыдущую серию. Но у последней серии нет следующего символа, который ее закроет. Поэтому после цикла может понадобиться отдельное действие. Это распространенная причина потери последних данных, даже когда середина строки обработана верно.

В этих задачах последовательности конечны и малы. Цикл `while`, условие остановки, вложенные обходы и более эффективная сборка больших строк появятся дальше; для первых решений они не нужны.

### Проверьте понимание

Почему `count_marks("")` возвращает ноль? Не потому, что цикл нашел особый пустой символ. Тело не выполнилось ни разу, а `count` сохранил начальное значение. Такое рассуждение помогает проверить пустой ввод без отдельной ветки.
