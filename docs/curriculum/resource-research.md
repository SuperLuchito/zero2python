# Подборка русскоязычных материалов

Дата проверки ссылок: 2026-09-07. Поиск: Exa; дополнительный веб-поиск для точных YouTube-страниц. Основной формат — видео. Каталог охватывает 33 темы: 61 размещений видео (58 уникальных), 14 размещений статей, 48 различных задач LeetCode (99 размещений; обновлено 2026-09-08). В проектах некоторые источники повторяются для закрепления.

## Основной плейлист Python

По последнему поручению основой базы стал [«Python для начинающих» Ивана Викторовича](https://www.youtube.com/playlist?list=PLs2IpQwiXpT1Dusi6jbWTfS7xBGyZK9Ox). Все 25 видео распределены по темам, оригинальные номера сохранены. Exa подтвердил состав; точные ссылки, русские названия и длительности прочитаны с самой страницы YouTube в браузере. Полный просмотр всех 25 уроков не выполнялся. Список тем платформы группирует видео по предмету, поэтому его порядок отличается от номеров в плейлисте. Установка Python/PyCharm нужна для локальной практики, для встроенного редактора не требуется.

## Отбор и пределы проверки

- selfedu: конкретные видеоссылки извлечены из соответствующих страниц автора proproprogs.ru. Для выбранных исходных видео проверены названия и автор через YouTube oEmbed; текст статьи использован для сопоставления темы.
- Артём Шумейко (pytest), PyLounge (Jupyter), Руслан Сенаторов (pandas), Вадим Новосёлов (алгоритмы), Алексей Коледачкин (requests): проверены публичные страницы; для доступных роликов прочитан текстовый материал/транскрипт. Полный аудиовизуальный просмотр всех роликов не выполнялся.
- Материалы о фундаментальном Python могут быть опубликованы раньше 2026 года. Дата проверки ссылки не выдаётся за дату публикации. Версионные оговорки размещены рядом с ресурсом.
- Из старого материала pandas Физтех.Статистики исключён из обязательного чтения раздел df.append; использовать concat. NumPy: явные dtype, без старых алиасов. Jupyter: старый интерфейс и плагины не являются инструкцией для современной установки.
- Не включены закрытые видео МФТИ с доступом через phystech.edu, случайные перезаливы и английские ролики. Стартовое объяснение dict на selfedu с утверждением о неупорядоченности заменено справкой METANIT; видео про операции словаря сохранено с явной оговоркой о порядке.
- LeetCode: проверены публичные страницы задач, к ним написаны короткие русские условия. Отправка решения требует аккаунта LeetCode. Скриншот — локальное подтверждение участника, не независимая оценка его ответа.
- Начальные LeetCode-задачи могут требовать return, циклы или списки; эти предпосылки указаны. Их можно завершить после соответствующей базовой темы. Ничего не блокируется по кругу.
