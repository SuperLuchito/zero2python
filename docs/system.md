## Существующий каркас

Факты ниже установлены по исходникам и `package.json`, а не являются выбором новой архитектуры.

| Часть | Реализация |
| --- | --- |
| Приложение | Next.js `^15.5.9`, React `19.1.1`, TypeScript `5.9.2`; точное разрешение зависимостей — в `package-lock.json` |
| Маршруты | `app/`: загрузочный экран `/`, карта `/app`, урок `/app/lesson/[id]`, вопрос дня `/app/qotd` |
| Интерфейс | `components/`, общие стили `app/globals.css`; терминальное оформление |
| Уроки | `content/curriculum.ts`: модули base, pandas, algo, тексты, задания, подсказки и Python-проверки |
| Вопрос дня | `content/qotd.ts`, выбор по дате; UI в `components/QotdView.tsx` |
| Типы | `lib/types.ts`: Module, Lesson, Task, TaskMark, Qotd |
| Прогресс | `lib/storage.ts`, `localStorage` с ключом `py-term.v1`; без серверной синхронизации |
| Python | `lib/pyodide.ts`, Pyodide `0.26.4` с jsDelivr; numpy/pandas загружаются по необходимости |

Регистрация, серверное хранение прогресса и открытие анализа данных по предпосылкам еще не реализованы. `Roadmap` выводит прямые ссылки на все уроки. Проверки заданий поставляются клиенту и запускаются вместе с кодом ученика в браузере; они не являются серверной проверкой знаний.

## Команды

```bash
npm ci
npm run dev
node node_modules/typescript/bin/tsc --noEmit --incremental false
npm run build
npm start
```

В ходе настройки 2026-09-05 выполнена проверка типов с `--noEmit --incremental false`, результат успешный. Сборка, повторная установка зависимостей и браузерный сценарий на этом этапе не запускались. Отдельных скриптов lint/test и CI пока нет.

Загрузка Pyodide требует сети. Шрифт подключен через `next/font/google`, что следует учитывать при проверке сборки в среде с ограниченной сетью.

## Контракты, требующие решения перед реализацией

| Область | Что необходимо определить | Когда |
| --- | --- | --- |
| Учебный контент | Формат урока, задания, ответа и ссылки на источник | При наполнении |
| Прогресс | Что означает освоенная тема и как сохраняется результат | До открытия разделов по условиям |
| Предпосылки | Какие темы Python нужны конкретным задачам анализа данных | После получения университетского курса |
| Выполнение Python | Достаточно ли текущего Pyodide для курса; нужны ли лимиты исполнения и другой способ проверки | При расширении практики |
| Учетная запись | Способ входа, восстановление доступа, необходимые данные | На этапе регистрации |
| Развертывание | Хостинг, конфигурация и эксплуатационные проверки | Перед деплоем |

Это открытые решения для развития каркаса. Вопросы ведутся в [questions.md](questions.md), существенные решения — в [журнале ADR](decisions/README.md).

## Проверки текущего этапа

Проверять YAML навыков и GitHub-шаблонов, локальные ссылки Markdown и согласованность названий меток. Изменения конфигурации не должны менять исходники приложения. CI старого Python-проекта не переносится: его команды не соответствуют стеку этого каркаса.
