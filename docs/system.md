# Система и разработка

Актуально для выпуска 2026-09-09. Репозиторий: `SuperLuchito/zero2python`, основная ветка `main`.

## Архитектура

Next.js 15.5.25, React 19, TypeScript. App Router экспортирует статические страницы. `scripts/build-sites.mjs` собирает клиентские файлы в `dist/client` и Worker API в `dist/server/index.js`. Sites размещает Worker, статические файлы, D1 и R2. Next.js-сервер в продакшене не работает.

## Вход и прогресс

Никнеймы Lukyan, Maria, Egor проверяются сервером без учёта регистра. Паролей нет по прямому поручению: это выбор профиля для доверенной команды, любой посетитель может выбрать любой из трёх ников. Cookie случайной сессии HttpOnly, SameSite=Strict, Secure на HTTPS, срок 30 дней. Выход отзывает сессию. Сервер проверяет Origin записей и определяет профиль из сессии. Заголовок ожидаемого профиля предотвращает случайную запись после смены аккаунта в другой вкладке.

Таблица D1 `progress`: профиль, вид, ключ, JSON-значение, дата обновления. Записи независимы: task, qotd, просмотр материала, книга, подтверждение LeetCode. Сервер фильтрует допустимые ID по собранному каталогу, не принимает произвольные задачи. Успешное решение не снимается нажатием «Сдаться». Один ответ дня сохраняется один раз. Место в рейтинге зависит только от решённых задач Python; равные результаты дают места 1, 1, 3.

В localStorage — кеш результатов и очередь несинхронизированных изменений, разделённые по профилям. Очередь очищается после подтверждения сервера. При недоступности сети UI сообщает об ожидании синхронизации, попытки повторяются. Начальный вход требует сети. Черновики кода локальны, по профилю/теме/задаче. Старые нескопированные результаты этого браузера относятся к Lukyan; старые ключи не удаляются. ID прежнего курса не входят в новые счётчики. Старые скриншоты IndexedDB не удаляются и автоматически не публикуются; при наличии их нужно повторно прикрепить.

R2 хранит скриншоты до 8 МБ: PNG, JPEG, WebP. Клиент проверяет декодирование, сервер — размер, MIME и сигнатуру. Зачёт записывается только через успешную загрузку. Содержимое Accepted не анализируется; это подтверждение участника. Просмотр/удаление привязаны к выбранному профилю.

## Учебный сценарий

Оглавление модуля содержит три визуально разделённые зоны: лекции, практика, LeetCode. В теме отображается один этап. «Далее: практика» доступна после всех отметок изучения; «Далее: LeetCode» — после всех встроенных задач. Прямые ссылки из оглавления позволяют вернуться к любому этапу, но сами по себе зачёт не дают.

Тема завершена после всех материалов, решений Python и подтверждений LeetCode. Подсказки допустимы; «Сдаться» не засчитывается. В каждой теме три задачи LeetCode, включая Medium. Предпосылки ранних сложных задач указаны: к ним можно вернуться после следующих тем.

Для базы Python сохранены все 25 видео указанного пользователем плейлиста Ивана Викторовича. Номера автора не меняются. YouTube открывается во встроенном плеере или по прямой ссылке; видео не копируются. Архив авторских лекций остаётся в `docs/curriculum`, но не подменяет текущие карточки внешних материалов.

Книжный курс основан на предоставленном издании: Эндрю Траск, Питер, 2019, ISBN 978-5-4461-1334-7. Отметки чтения независимы от правильных ответов; тест главы пройден после трёх верных ответов. Объяснения указывают печатную страницу и номер PDF (+1). Пошаговые схемы — оригинальные учебные иллюстрации, а не точные рисунки книги. Полный текст/PDF не публикуется.

Для анализа данных показывается честное ожидание материалов. Перечень обязательных тем Python определяется после их получения.

## Исполнение и отладка

Pyodide 0.26.4 выполняет ученический Python только в Web Worker браузера. «Запустить код» не проверяет решение и не меняет зачёт. «Проверить решение» выполняет код и тесты; зачёт получает только успешный результат. Тесты доступны клиенту и не защищены от намеренного обхода.

Лимит запуска — 15 секунд, загрузки пакетов — 180 секунд. По тайм-ауту Worker завершается и может быть создан заново. stdout ограничен 60 тысячами символов, matplotlib — 6 PNG. Виртуальные файлы исчезают при сбросе.

Трасса sys.settrace показывает до 200 шагов `solution.py`, состояние после строки, область видимости, возвращаемое значение и stdout. Не трассируются библиотеки и текст тестов. Указывается фаза запуска или вызова из проверки. Коллекции и строки сокращаются; сложные объекты показаны именем типа. Это не просмотр внутренностей NumPy и не выполнение отдельных операций внутри строки. Промежуточные кадры списковых включений пропускаются для исключения побочного эффекта чтения locals в CPython 3.12.

Ошибки относятся к строке редактора только когда источник — `solution.py`. Ошибки автотестов не подсвечивают случайную строку. Автодополнение предлагает переменные из предыдущих присваиваний, параметров и циклов; ключевые слова, функции, комментарии и строки исключены. Это лексический анализ, а не полный анализ областей видимости.

Вопрос дня выбирается по дате браузера после монтирования. После ответа доступен реальный запуск с пошаговым разбором; при проблеме с CDN есть повтор загрузки.

## Запуск и проверки

```bash
npm ci
npm run build
npm run db:local
npm start -- --ip 127.0.0.1 --port 3010
```

`npm run dev` — только интерфейс Next.js без API. `npm start` / `npm run preview` — Wrangler со статической сборкой и локальными D1/R2. Локальная схема генерируется `npm run db:generate`; production-миграции применяет Sites при публикации. Применённые SQL и метаданные не редактировать.

Проверки: TypeScript `--noEmit --incremental false`, `tests/materials.cjs`, `tests/book.cjs`, `tests/accounts.mjs`, `tests/completion.cjs`, `tests/highlight.cjs`, `tests/markdown.cjs`. Для Pyodide: `tests/worker.cjs`, `scripts/verify-pyodide.cjs` с `PYODIDE_PACKAGE` версии 0.26.4. Проверки аккаунтов используют изолированную тестовую SQLite в памяти, без реальных результатов.

WebMCP `read_team_progress` возвращает тот же рейтинг, что UI, без изменения данных. Регистрация необязательна для браузера и проверяется по наличию API.

Секреты, PDF, реальные результаты, `.wrangler`, `.next`, `dist`, `out`, `node_modules` и временные артефакты не публикуются. См. [ADR Sites](decisions/0004-sites-team-book.md).

Старые адреса `/app/progress` и `/app/progress/leaderboard` открывают профиль и актуальный общий рейтинг. Прежний синтетический тест книги заменён предоставленным изданием.

Проверка выпуска: вход Lukyan сохраняет 1/79; из профиля Egor виден этот же результат команды. Отметка чтения и верный ответ главы пережили перезагрузку; тестовые записи удалены из локальной базы. Неверный ответ показывает разбор без зачёта, анимация доходит до вычисленного 0.7. На ширине 390 px нет переполнения страницы. WebMCP проверен на корректный и неверный вход.
