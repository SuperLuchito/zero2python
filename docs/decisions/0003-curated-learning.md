# 0003. Внешние материалы и подтверждение прогресса

Дата: 2026-09-07
Статус: Принято по прямому поручению пользователя
Связи: [Продукт](../product.md), [исследование источников](../curriculum/resource-research.md), заменяет часть [0002](0002-curriculum-worker.md) об авторских лекциях.

## Контекст
Команда изменила подход: вместо написания лекций нужны русскоязычные видео YouTube, дополнительные статьи, практика Python и задачи LeetCode с подтверждением скриншотом.

## Варианты
Продолжение авторского курса требует постоянного написания и сопровождения лекций. Каталог внешних ссылок проще, но сам по себе не связывает изучение с практикой. Выбран каталог внутри существующего сценария темы с общим прогрессом.

## Решение
Материалы хранятся в content/resources.json и объединяются с существующими заданиями по стабильному идентификатору темы. Основной плейлист базы Python — 25 видео Ивана Викторовича, выбранные пользователем. LeetCode вынесен в отдельный этап темы после практики. Видео имеет приоритет; в карточке доступны плеер YouTube, внешняя ссылка, пояснение и отметка изучения. Лекции из прежнего набора остаются в архиве, но не выводятся в интерфейсе.

Тема завершена после ручных отметок всех материалов, прикрепления скриншотов всех внешних задач и успешных проверок всех встроенных заданий. Подсказки допускаются, «Сдаться» не засчитывается. Темы открыты: для задач, требующих последующих знаний, явно указаны предпосылки. Последнее встроенное задание обозначено итоговым.

Отметки сохраняются в localStorage, изображения — в IndexedDB. Скриншот является подтверждением ученика, а не автоматической проверкой Accepted. Python остаётся в Web Worker и загружается при открытии практики.

## Последствия
Материалы и ссылки требуют периодической проверки; рядом с несовместимыми старыми API указаны оговорки. Сам LeetCode англоязычный, поэтому карточки содержат русское пояснение и предпосылки. Видео зависит от доступности YouTube; остаётся прямая ссылка.

Данные сохраняются только в текущем браузере, без аккаунтов и синхронизации между устройствами. Очистка хранилища удалит результаты и изображения. Проверки охватывают состав каталога, правила зачёта, сохранение отметок, загрузку изображения и переход к исполнению Python.


## Уточнение 2026-09-08

По новым аннотациям этапы идут последовательно: лекции → встроенная практика → LeetCode. Оглавление модуля даёт прямые ссылки на все три группы. В каждой теме три задачи LeetCode, включая Medium. Завершение этапа не подменяется открытием ссылки. Примеры встроенных задач хранятся структурно. Пошаговая демонстрация строится на реальной трассе клиентского Python после запуска; отдельного серверного исполнителя или симулятора Python нет.

Часть о localStorage/IndexedDB заменена [0004](0004-sites-team-book.md) при добавлении общих профилей.
