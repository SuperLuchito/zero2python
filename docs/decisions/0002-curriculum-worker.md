# 0002. Авторский курс и Python в Worker

Дата: 2026-09-07. Статус: Принято по прямому поручению дописать и встроить весь курс.

Часть решения об авторских лекциях заменена [0002](0003-curated-learning.md). Исполнение в Worker сохраняется; загрузка Python теперь начинается при открытии практики.

## Контекст
Полные лекции требуют Markdown, таблиц и нескольких подсказок. Практика while может бесконечно занять основной поток браузера. NumPy, pandas, графики и SQLite нужны конкретным темам.

## Решение
Сохраняем Next.js и Pyodide 0.26.4. Генерируем JSON из авторских файлов с обязательным выполнением эталонов. Исполнение переносим в Web Worker; основной поток прекращает зависший запуск через 15 секунд. Пакеты загружаются при открытии темы, графики возвращаются как PNG. Notebook для локальных проектов распространяются с фиксированными зависимостями.

## Варианты и последствия
Основной поток не позволяет надёжно прервать бесконечный цикл. Серверный Python потребовал бы отдельной изоляции и не нужен текущему локальному продукту. Worker сохраняет клиентскую границу, но не гарантирует лимит памяти и не защищает учебные проверки от намеренного обхода. После остановки теряются виртуальные файлы и состояние Python. Черновик редактора сохраняется отдельно. Полноценный PyTorch и системные команды остаются локальными практикумами, обозначенными в лекциях.
